# Moodist 详细设计文档

## 1. 系统架构设计

### 1.1 整体架构
Moodist 采用现代化的前端架构，结合了静态站点生成和客户端应用的优点。

### 1.2 技术栈选择

#### 前端框架
- **Astro**: 静态站点生成器，提供优秀的性能
- **React**: 组件化开发，生态丰富
- **TypeScript**: 类型安全，提高代码质量

#### 状态管理
- **Zustand**: 轻量级状态管理，支持持久化
- **React Context**: 全局状态共享

#### UI组件库
- **Radix UI**: 无样式、可访问的UI组件
- **React Icons**: 丰富的图标库
- **Framer Motion**: 流畅的动画效果

#### 音频处理
- **Howler.js**: 跨浏览器音频库

#### 构建工具
- **Vite**: 快速的开发服务器和构建工具
- **PostCSS**: CSS处理器

## 2. 核心模块设计

### 2.1 音效播放模块

#### 2.1.1 模块职责
- 管理音效的播放、暂停、停止
- 控制音效音量
- 处理音效加载状态
- 支持多音效混音

#### 2.1.2 核心类设计

```typescript

  // 停止音效

  // 淡出效果
  fadeOut(duration: number): void;

  // 设置音量
  setVolume(volume: number): void;
```

#### 2.1.3 数据流设计

```
用户点击音效卡片
       ↓
   select(id) Action
       ↓
  Zustand Store更新
       ↓
  Sound组件检测状态变化
       ↓
  useSound Hook响应

       ↓

```

### 2.2 状态管理模块

#### 2.2.1 状态结构设计

```typescript
// 音效状态接口
interface SoundState {
  // 获取收藏的音效ID列表
  getFavorites(): string[];

  // 全局音量 (0-1)
  globalVolume: number;

  // 历史状态备份
  history: SoundSnapshot | null;

  // 播放状态
  isPlaying: boolean;

  // 锁定状态（防抖）
  locked: boolean;

  // 检查是否没有选中音效
  noSelected(): boolean;

  // 所有音效的状态
  sounds: Record<string, SoundStatus>;
}

// 单个音效状态
interface SoundStatus {
  isSelected: boolean;   // 是否被选中
  isFavorite: boolean;   // 是否被收藏
  volume: number;        // 音量 (0-1)
}
```

#### 2.2.2 操作方法设计

```typescript
interface SoundActions {

  setGlobalVolume(volume: number): void;

  // 播放/暂停切换
  togglePlay(): void;

  // 播放
  play(): void;

  // 暂停
  pause(): void;

  // 随机选择音效
  shuffle(): void;

  // 切换收藏状态
  toggleFavorite(id: string): void;

  // 锁定状态
  lock(): void;
  unlock(): void;

  // 恢复历史状态
  restoreHistory(): void;

  // 覆盖当前状态（用于分享链接）
```

```
       ↓
   音效播放/停止
       ↓
   播放状态更新
       ↓
   媒体会话API更新
```

## 5. 性能优化设计

### 5.1 渲染优化

#### 5.1.1 React优化策略
- 使用`useMemo`缓存计算结果
- 使用`useCallback`缓存事件处理函数
- 使用`React.memo`避免不必要的重渲染
- 使用`useShallow`选择器避免深度比较

#### 5.1.2 列表渲染优化
```typescript
// 使用稳定的key
<Sounds>
  {sounds.map(sound => (
    <Sound key={sound.id} {...sound} />
  ))}
</Sounds>

// 虚拟滚动（大量数据时）
import { useVirtualizer } from '@tanstack/react-virtual';
```

### 5.2 音频优化

#### 5.2.1 音效加载优化
- 懒加载：只在需要时加载音效
- 预加载：常用音效提前加载
- 缓存策略：已加载的音效缓存复用

#### 5.2.2 音频播放优化
- 使用Web Audio API（现代浏览器）
- 降级到HTML5 Audio（兼容性）
- 音效格式优化（MP3 vs WebM）

### 5.3 网络优化

#### 5.3.1 资源优化
- 图片压缩和WebP格式
- 音效文件压缩
- CDN加速
- HTTP/2多路复用

#### 5.3.2 缓存策略
- Service Worker缓存静态资源
- 浏览器缓存策略
- LocalStorage缓存用户数据

## 6. 安全设计

### 6.1 数据安全
- 所有数据存储在客户端
- 不收集用户个人信息
- 不上传任何用户数据

### 6.2 内容安全
- 所有外部链接使用`rel="noopener noreferrer"`
- 音效文件来自可信源
- 防止XSS攻击
