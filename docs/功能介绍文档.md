# Moodist 功能介绍文档

## 1. 应用概览

Moodist 是一个专注于提升用户专注力、放松状态和创造力的环境音效生成器。通过精心设计的自然和城市环境音效，帮助用户创造理想的工作、学习或休息氛围。

### 1.1 核心价值
- **专注提升**：通过环境音效屏蔽干扰，提升工作学习效率
- **压力缓解**：自然音效帮助放松身心，减轻压力
- **睡眠辅助**：白噪音和环境音效改善睡眠质量
- **创意激发**：特定音效组合激发创作灵感
- **完全免费**：开源项目，无需付费即可使用所有功能

### 1.2 设计理念
- **极简主义**：界面简洁，功能聚焦
- **东方美学**：采用传统东方配色，营造平静氛围
- **用户至上**：所有设计都以用户体验为出发点
- **隐私保护**：所有数据本地存储，不上传任何信息

## 2. 核心功能详解

### 2.1 音效播放系统

#### 2.1.1 功能描述
Moodist 的核心是强大的多音效播放系统，支持同时播放多个音效，创造个性化的声音环境。

#### 2.1.2 使用方法

**选择音效**：
1. 浏览不同的音效分类（自然、雨声、城市等）
2. 点击任意音效卡片即可选中/取消
3. 选中的音效会自动开始播放
4. 可以同时选择多个音效进行混音

**音量控制**：
- 每个音效都有独立的音量滑块
- 拖动滑块可以精确控制音量（0-100%）
- 全局音量控制可以同时调整所有音效

**播放控制**：
- 点击"Play"按钮开始播放所有选中的音效
- 点击"Pause"按钮暂停播放
- 点击"Unselect All"按钮取消所有选择

#### 2.1.3 功能特点
- **即时响应**：音效加载和播放几乎无延迟
- **智能预加载**：常用音效提前加载，提升体验
- **无缝循环**：所有音效都支持无缝循环播放
- **音效淡入**：选中音效时自动淡入，避免突兀
- **混音优化**：多音效同时播放时自动优化混音效果

#### 2.1.4 支持的音效类型

**自然音效**：
- 河流声
- 海浪声
- 篝火声
- 风声（多种强度）
- 树林风声
- 瀑布声
- 雪地行走声
- 树叶声
- 碎石声
- 水滴声
- 丛林声

**雨声音效**：
- 轻柔雨声
- 中等雨声
- 暴雨声
- 雷雨声
- 屋檐滴水声
- 雨滴声

**动物音效**：
- 鸟叫声
- 蟋蟀声
- 青蛙声
- 猫叫/狗叫
- 昆虫声

**城市音效**：
- 咖啡馆环境音
- 街道声音
- 交通噪音
- 办公室背景音
- 人群嘈杂声

**其他分类**：场所、交通、物品、噪音等多种环境音效

### 2.2 收藏功能

#### 2.2.1 功能描述
收藏功能让用户可以快速访问常用的音效，无需在众多音效中寻找。

#### 2.2.2 使用方法
1. 点击任意音效卡片右上角的❤️图标
2. 图标变为实心❤️表示已收藏
3. 再次点击取消收藏
4. 收藏的音效会自动出现在"Favorites"分类中

#### 2.2.3 功能特点
- **持久化保存**：收藏状态自动保存，关闭浏览器后仍然保留
- **动态分类**：有收藏音效时自动显示"Favorites"分类
- **一键访问**：收藏音效集中在顶部，方便快速访问
- **无数量限制**：可以收藏任意数量的音效

### 2.3 预设管理

#### 2.3.1 功能描述
预设功能允许用户保存当前的音效配置，包括选中的音效和各自的音量设置，方便快速恢复特定的声音环境。

#### 2.3.2 使用方法

**创建预设**：
1. 选择需要的音效并调整到合适的音量
2. 打开工具栏菜单（点击右下角菜单按钮）
3. 选择"Presets"
4. 点击"New Preset"
5. 输入预设名称
6. 点击"Save"保存

**使用预设**：
1. 打开"Presets"面板
2. 点击任意预设即可应用
3. 系统会自动选择对应的音效并设置音量

**管理预设**：
- **重命名**：点击预设名称旁的编辑图标
- **删除**：点击预设的删除图标
- **排序**：新创建的预设会显示在列表顶部

#### 2.3.3 应用场景
- **工作模式**：保存适合工作的音效组合
- **阅读模式**：保存适合阅读的轻柔音效
- **睡眠模式**：保存助眠的平静音效
- **冥想模式**：保存适合冥想的专注音效

### 2.4 分享功能

#### 2.4.1 功能描述
分享功能让用户可以将当前音效配置分享给朋友或保存到其他设备。

#### 2.4.2 使用方法
1. 调整好想要的音效配置
2. 打开工具栏菜单
3. 选择"Share Sounds"
4. 点击复制按钮复制链接
5. 将链接发送给朋友或在其他设备打开

#### 2.4.3 功能特点
- **一键复制**：快速复制分享链接到剪贴板
- **自动应用**：打开链接后自动应用音效配置
- **跨设备同步**：在不同设备间快速同步设置
- **隐私保护**：不包含任何个人信息，只是音效配置

### 2.5 睡眠定时器

#### 2.5.1 功能描述
睡眠定时器让用户可以设置在指定时间后自动停止播放，适合睡前使用或需要定时停止的场景。

#### 2.5.2 使用方法
1. 打开工具栏菜单
2. 选择"Sleep Timer"
3. 选择想要的时间（5分钟到2小时）
4. 点击"Start"开始计时
5. 时间到后音效会淡出停止

#### 2.5.3 功能特点
- **淡出效果**：时间到后音效会缓慢淡出，避免突然停止
- **灵活时间**：支持5分钟到2小时的自定义时间
- **实时显示**：显示剩余时间
- **可取消**：随时可以取消定时器

#### 2.5.4 使用场景
- **睡前助眠**：设置30分钟后自动停止
- **午休小憩**：设置20分钟后唤醒
- **专注时段**：设置1小时后提醒休息

## 3. 实用工具箱

### 3.1 番茄钟

#### 3.1.1 功能描述
基于番茄工作法的专注计时器，帮助用户提高时间管理效率。

#### 3.1.2 功能特点
- **三种模式**：
  - 番茄时间（默认25分钟）：专注工作时段
  - 短休息（默认5分钟）：短暂休息
  - 长休息（默认15分钟）：较长休息

- **自定义设置**：
  - 可以调整每种模式的时间长度
  - 设置会自动保存

- **统计功能**：
  - 记录每种模式的完成次数
  - 帮助用户了解工作节奏

- **操作控制**：
  - 开始/暂停计时
  - 重置计时器
  - 快速切换模式

#### 3.1.3 使用建议
- 工作时使用25分钟番茄时间
- 每4个番茄后使用长休息
- 短休息用于短暂放松
- 长休息用于充分休息

### 3.2 记事本

#### 3.2.1 功能描述
简单的文本编辑器，让用户可以快速记录想法、待办事项或笔记。

#### 3.2.2 功能特点
- **实时保存**：内容自动保存，不会丢失
- **简洁界面**：无干扰的写作环境
- **富文本支持**：基本的文本格式化
- **本地存储**：所有数据保存在本地

#### 3.2.3 使用场景
- 工作时快速记录灵感
- 会议时做笔记
- 记录待办事项
- 写作草稿

### 3.3 待办事项

#### 3.3.1 功能描述
任务管理工具，帮助用户组织和跟踪待办事项。

#### 3.3.2 功能特点
- **任务管理**：
  - 添加新任务
  - 标记任务完成
  - 删除任务

- **状态跟踪**：
  - 区分已完成和未完成任务
  - 显示完成进度

- **数据持久化**：
  - 自动保存所有任务
  - 关闭后数据不丢失

#### 3.3.3 使用建议
- 将大任务分解为小任务
- 优先处理重要任务
- 定期检查和更新任务列表

### 3.4 倒计时

#### 3.4.1 功能描述
灵活的倒计时工具，适用于各种计时需求。

#### 3.4.2 功能特点
- **自定义时长**：设置任意时长的倒计时
- **实时显示**：显示剩余时间
- **提醒功能**：时间到后播放提醒音
- **操作简单**：开始、暂停、重置等基本操作

#### 3.4.3 使用场景
- 会议计时
- 练习计时
- 烹饪计时
- 运动计时

### 3.5 呼吸练习

#### 3.5.1 功能描述
引导式呼吸训练，帮助用户放松身心，减轻压力。

#### 3.5.2 功能特点
- **呼吸指导**：
  - 视觉引导（圆形呼吸动画）
  - 文字提示（吸、呼、保持）
  - 节奏控制

- **多种模式**：
  - 放松模式（缓慢呼吸）
  - 平衡模式（均匀呼吸）
  - 活力模式（快速呼吸）

- **自定义设置**：
  - 调整呼吸时长
  - 选择适合的模式

#### 3.5.3 使用建议
- 工作间隙进行5分钟呼吸练习
- 睡前进行放松模式
- 压力大时使用平衡模式

### 3.6 双耳节拍

#### 3.6.1 功能描述
利用双耳节拍技术帮助用户进入不同的脑波状态，提升专注力或放松状态。

#### 3.6.2 功能特点
- **多种频率**：
  - Delta波（1-4Hz）：深度睡眠
  - Theta波（4-8Hz）：深度放松
  - Alpha波（8-13Hz）：放松专注
  - Beta波（13-30Hz）：活跃思考

- **自定义设置**：
  - 选择想要的脑波频率
  - 调整音量和时长
  - 选择背景音效

#### 3.6.3 使用建议
- 需要深度专注时使用Beta波
- 需要放松时使用Alpha波
- 冥想时使用Theta波
- 睡眠时使用Delta波

### 3.7 等时节拍

#### 3.7.1 功能描述
播放等间隔的节拍声，用于节奏训练、音乐练习或专注。

#### 3.7.2 功能特点
- **节拍控制**：
  - 设置节拍频率（BPM）
  - 选择节拍音效
  - 调整音量

- **多种节拍**：
  - 简单节拍
  - 复杂节拍模式
  - 自定义节拍

#### 3.7.3 使用场景
- 音乐练习
- 节奏训练
- 专注工作
- 冥想引导

### 7.2 高效使用技巧

#### 7.2.1 工作流程优化
1. **预设准备**：提前为不同工作场景创建预设
2. **快捷键使用**：熟练使用键盘快捷键提高效率
3. **音效平衡**：合理调节各音效音量，避免某音效过于突出
4. **定时提醒**：使用番茄钟或睡眠定时器定时休息

#### 7.2.2 环境优化建议
- 使用耳机获得更好体验
- 调节合适的总体音量
- 在安静环境中使用效果更佳
- 定期休息，避免长时间使用

#### 7.2.3 个人化定制

## 8. 故障排除

### 8.1 常见问题

#### 8.1.1 音效无法播放
**可能原因**：
- 浏览器自动播放策略限制
- 网络连接问题
- 音效文件加载失败

**解决方法**：
- 手动点击播放按钮
- 检查网络连接
- 刷新页面重试

#### 8.1.2 音效卡顿
**可能原因**：
- 同时播放音效过多
- 设备性能不足
- 网络延迟

**解决方法**：
- 减少同时播放的音效数量
- 关闭其他占用资源的程序
- 检查网络连接

#### 8.1.3 设置丢失
**可能原因**：
- 清除了浏览器缓存
- 使用了隐私浏览模式
- 更换了浏览器

**解决方法**：
- 正常模式下使用应用
- 避免清除浏览器缓存
- 定期备份重要设置

### 8.2 性能问题

#### 8.2.1 内存占用高
**解决方法**：
- 减少同时播放的音效
- 关闭不需要的工具
- 刷新页面重置状态

#### 8.2.2 电池消耗快
**解决方法**：
- 降低音量
- 减少同时播放的音效
- 使用省电模式
- 连接充电器使用
